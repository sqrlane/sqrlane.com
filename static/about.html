What is real and what is not
“The risk detection is real — it runs against live news right now. The shipments are synthetic, so I can show you a disruption on demand instead of waiting for one.”
Live news pull, classification, decisions, drafts Synthetic the seven bookings and the injected Hamburg strike Demo connector the TMS the bookings are read from and written back to

The injected strike uses the same event format as a live one, so it runs through the real pipeline rather than around it. The TMS link is the same idea in reverse: one door to the book, every decision written back onto the record it came from, but no TMS contacted and nothing written. A demo, not a live product — the wall between the two is integration and trust, and this connector stops at it.

Who it is for

The desk that is doing both halves by hand.

Modelled end user

Head of Operations at a mid-size forwarder

DACH or Benelux, running the North Range corridors. Big enough that a Hamburg strike touches several bookings at once; too small for the enterprise risk platforms, which stop at the alert anyway.

The job it removes

Re-keying the consequences, one booking at a time

Watching is narrower than the problem and reacting is slower than the problem. The plank that eats the day is the second one: typing each decision into the system of record by hand.

Scope

What it deliberately does not do.

Each of these is a decision, not a gap — and saying so is cheaper than being found out.

No live TMS connection

Working through the TMS is the design; the far end is not built. No vendor, no credential, no endpoint, and nothing is ever written.

Nothing is sent

No email library and no transport of any kind is imported anywhere in the app. A test parses every file and fails the build if one appears.

No route optimisation

Routes are pre-authored candidates. The agent chooses among them and justifies the choice; it does not compute them.

No accuracy figures

Nothing here has been measured against real freight, so no percentage is claimed anywhere on this site. An invented number is the one thing this project refuses to produce.

No scheduler

Button-triggered. For a demo, the magic has to happen on screen, on command — not in a background job nobody can see.

No database

JSON files and memory. There is nothing to install and nothing to migrate.
