What it reads

Sixty sources. Not one of them load-bearing.

Breadth is only safe because nothing depends on any single source. Each sits behind its own small function inside a shared budget, and one that is down, slow or quietly reshaped is reported failed and skipped while the run carries on.

SourceRoleKey
GDELT DOC 2.0 11 queries The news backbone, refreshing about every 15 minutes. One query per corridor — North Range, Low Countries, Western Mediterranean, Red Sea and Gulf, Asian gateways, the Turkish straits, Panama — plus one on customs and tariffs. None
RSS 30 feeds Broadcasters and papers on the corridors' doorsteps — NDR Hamburg, tagesschau, DW, ORF, NOS, Rijnmond, VRT, RTVE, El País, Le Monde, ANSA, NHK, BBC عربي, France 24, Egypt Independent, News24, The Straits Times — plus the trade press: gCaptain, Splash 247, The Maritime Executive, The Loadstar, Container News, FreightWaves. Reading close to the event is why one of them is usually first; the international feeds stay so the lead over them is measurable. None
PEGELONLINE 6 gauges Rhine levels at Kaub, Duisburg-Ruhrort, Emmerich, Köln, Mainz and Maxau — the three gauges the barge market quotes, plus three upriver so a falling reach is seen early. Read by threshold, never by the model. None
Open-Meteo wind + sea + flood Gusts over Hamburg, Rotterdam, Antwerp and Fos-sur-Mer, wave height at the Suez approaches, Bab-el-Mandeb and the Cape. A terminal loses crane hours near gale force 8, so the bands are an operator's own. Its flood endpoint adds modelled flow for the Rhine reach, so the river is read two independent ways. None
DWD warnings The authority's own open warning feed, matched by region to the chokepoints on the board. A warning in force is a different signal from a forecast gust; below the severe level it stays context and moves nothing. None
USGS · EMSC · NASA EONET · GDACS hazards Seismic activity from two independent networks, banded identically so they cannot call the same quake apart; NASA's tracker for wildfires, storms, floods and volcanoes; the UN and Commission's disaster alerts. Each reading carries a coordinate and is dropped if no corridor is within reach — a magnitude 7 in the South Pacific is real and is not this board's problem. None
Federal Register filings Tariff, sanctions, customs and port-security filings, which land as a government document days before a trade paper writes them up. Prose, so it goes to the model. None
Frankfurter · NWS · NHC · HK Observatory context The ECB's own reference rates, US weather alerts, NOAA's named storms and the warnings over the Pearl River Delta. Real, read live, and they move nothing here — so they sit in their own panel saying exactly that. None
Runtime model Groq Resolved at runtime against the provider's own model list, never hard-coded — a retired name returns a 404 that looks exactly like a broken key. Yours

Not wired, deliberately: anything paid, anything that needs a key. Reuters retired its public feeds — a dead feed is a live failure — and OpenSanctions now gates its API behind a key, which "no API keys" cannot survive.
